# Almyra Café · demo concept

Demo για επιδείξεις σε πελάτες: φανταστικό café με **παραγγελία και παραλαβή σε ώρες που διαλέγει ο πελάτης**. Δεν είναι πραγματική επιχείρηση και οι παραγγελίες δεν στέλνονται πουθενά.

Live: https://varveroglouvasileios.github.io/CafeProject/

## Τι δείχνει
- Μενού με καλάθι και σύνολο.
- Επιλογή ώρας παραλαβής ανά 15 λεπτά, με **όριο παραγγελιών ανά ώρα** (οι μεγάλες παραγγελίες μετρούν διπλά). Γεμάτες και περασμένες ώρες κλείνουν. Ο έλεγχος επαναλαμβάνεται κατά την αποστολή.
- Εισιτήριο παραγγελίας με κωδικό.
- Οθόνη κουζίνας (`#/kitchen`, κωδικός `demo`): νέες → ετοιμάζονται → έτοιμες → παραδόθηκαν, με φορτίο ανά ώρα.

## Τεχνολογία
Vue 3, TypeScript, Tailwind, vue-router (hash history για GitHub Pages), Vitest. Η λογική (ώρες, χωρητικότητα, καλάθι, επικύρωση) είναι καθαρές συναρτήσεις στο `src/lib/pickup.ts` με tests. Τα δεδομένα μένουν στο `localStorage` και η κουζίνα έχει «Επαναφορά demo».

```bash
yarn install
yarn dev     # τοπικά
yarn test    # tests λογικής
yarn build   # production build
```

Οι φωτογραφίες είναι δημιουργημένες με AI και ενδεικτικές. Σχεδιασμός και υλοποίηση: Βασίλειος Βαρβέρογλου.
